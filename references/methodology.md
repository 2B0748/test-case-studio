# 测试设计方法库与方法论

本文件供 `test-case-studio` 在阶段2「测试设计」时按需加载，提供方法选择指引、
字段定义与优先级标准。

---

## 一、测试设计方法速查

| 方法 | 适用场景 | 关键动作 | 典型产出 |
|------|----------|----------|----------|
| 等价类划分 | 输入有取值范围/格式约束 | 划分有效/无效等价类 | 每类至少 1 条用例 |
| 边界值分析 | 数值/长度/日期有边界 | 取边界及±1 | 上点/离点/内点 |
| 判定表 | 多条件组合决定结果 | 列条件桩/动作桩 | 规则全覆盖 |
| 因果图 | 条件与结果有逻辑关联 | 画因果→判定表 | 组合去冗余 |
| 状态迁移 | 状态流转明显(订单/工单) | 画状态图+迁移事件 | 覆盖所有迁移+死状态 |
| 场景法 | 业务流程/用户旅程 | 基本流+备选流 | 每条流一条用例 |
| 错误推测 | 经验/历史缺陷高发 | 列易错清单 | 异常/破坏用例 |
| 正交试验 | 参数组合爆炸 | 选正交表 | 少量用例覆盖 pairwise |
| 两两组合 | 配置矩阵(兼容) | pairwise 工具 | 最小集覆盖 |

**组合策略**：等价类+边界值几乎必用；多条件→判定表；流程→场景法；
状态机→状态迁移；历史坑→错误推测。一个测试点可叠加多种方法。

## 二、通用用例字段（必填）

| 字段 | 说明 | 示例 |
|------|------|------|
| 用例编号 | 模块前缀+序号，全局唯一 | LOGIN-001 |
| 模块 | 一级功能模块 | 登录 |
| 子模块 | 二级功能 | 密码登录 |
| 用例标题 | 【类型】【预期】动作+对象 | 【功能】【正常】正确密码登录成功 |
| 用例类型 | 功能/接口/性能/安全/兼容 | 功能 |
| 设计方法 | 标注所用方法 | 等价类+边界值 |
| 优先级 | P0/P1/P2/P3 | P0 |
| 前置条件 | 执行前系统状态 | 用户已注册且未登录 |
| 测试步骤 | 每步一个可操作动作 | 1.打开登录页 2.输入账号 3.输入密码 4.点击登录 |
| 测试数据 | 步骤中使用的输入/账号 | 账号:test@x.com 密码:Pass@123 |
| 预期结果 | 可判定、可观测的结果 | 跳转首页，右上角显示用户名 |
| 需求追溯 | 对应需求/用户故事 ID | REQ-LOGIN-02 |

## 三、类型专属字段

### 接口(API)
- 请求方法/URL、请求头、请求体、鉴权方式
- 预期状态码、错误码
- 响应校验点：字段类型/必填/枚举/契约(schema)
- 专项：超时、幂等(重复提交)、并发、分页、大报文、边界参数

### 性能
- 并发用户数 / TPS 目标 / 响应时间目标(P95/P99)
- 持续时间、加压模型(阶梯/恒压)、思考时间
- 监控指标：CPU/内存/IO/连接数/慢查询/错误率
- 拐点与容量：找到系统拐点与最大容量

### 安全
- 漏洞类型：SQL注入 / XSS / 越权(水平/垂直) / 认证绕过 / 敏感信息泄露
- 攻击向量：具体 payload 或操作
- 预期防护：拦截/脱敏/拒绝，并给出期望响应

### 兼容
- 环境矩阵：OS / 浏览器及版本 / 机型 / 分辨率 / 网络(弱网)
- 预期表现：布局/功能/渲染一致，无脚本报错

## 四、优先级标准

| 级别 | 定义 | 典型对象 |
|------|------|----------|
| P0 | 核心主链路，失败即阻塞业务 | 登录、支付、下单主流程 |
| P1 | 重要功能，影响主要用户 | 关键筛选、核心配置 |
| P2 | 一般功能，边缘但需覆盖 | 次要设置、提示文案 |
| P3 | 边缘/低概率场景 | 极端输入、罕见组合 |

**经验法则**：单模块 P0 建议 ≤ 20%；P0 必须同时具备正向+边界+异常用例。
